# Widget preview artwork

`../src/main/res/drawable-nodpi/sherlock_holmes_portrait_with_pipe.webp` is a public-domain portrait of Sherlock Holmes, dated 1907 and attributed to Alfred Roloff (1879–1951). Wikimedia Commons lists the work as public domain and records its dimensions as 950 × 996 pixels, close to square:

- https://commons.wikimedia.org/wiki/File:Sherlock_Holmes,_portrait_with_pipe.png

The bundled image uses WebP quality 80 at the original dimensions to reduce APK size.

`../src/main/res/drawable-nodpi/player_widget_preview.png` is a capture of the generated player widget preview shown in the Android 17 widget picker. It uses the artwork above. Re-capture it if the widget preview design or artwork changes.
